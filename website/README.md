# MyTravelSafety — Website

Public marketing landing page. Deployed at **https://mytravelsafety.net**

Built with Next.js for full SSR and SEO. Fully indexable by Google.

## What this is

- Public-facing landing page only
- No app logic here — redirects users to the app
- SEO-optimized with server-side rendering
- Open Graph + Twitter Card + Schema.org built in

## Points to

- App: https://app.mytravelsafety.net
- Backend API: https://api.mytravelsafety.net

## Deploy

Push to GitHub → import in Vercel → set domain to `mytravelsafety.net`

No environment variables needed.
